CAPSTONE · UNITY GAME

Findy

AI-assisted Spot-the-Difference Game

국가별 스테이지를 선택해 제한 시간 안에 틀린 그림을 찾는 Unity 2D 게임입니다. 프롬프트로 생성한 이미지 기반의 커스텀 스테이지와 일반 스테이지 진행을 함께 구현했습니다.

  • Unity 2022.3
  • C#
  • URP
  • Unity UI
  • TextMesh Pro
  • UnityWebRequest

SPOT THE DIFFERENCE

FINDY

Find the difference. Build your stage.

Project Overview

Game Loop

국가를 고르고 스테이지에 진입해 두 이미지를 비교합니다. 터치 판정, 제한 시간, 정답 개수, 클리어 기록, 다음 스테이지 잠금 해제를 게임 흐름으로 연결합니다.

Custom Mode

사용자 프롬프트를 서버에 전달해 생성된 원본·차이·정답 이미지와 좌표 데이터를 받아, 플레이 가능한 커스텀 스테이지 데이터로 변환합니다.

Implemented Features

  • 국가와 스테이지를 데이터 객체로 분리한 스테이지 선택 구조
  • 60초 타이머·터치 정답 판정·승패 패널·다음 스테이지 진행
  • 힌트·시간 추가 등을 포함한 아이템 사용과 상점 구매 UI
  • 플레이 결과와 아이템 사용량의 서버 업로드 흐름
  • 프롬프트 기반 AI 커스텀 스테이지 생성 요청
  • Base64 이미지·정답 좌표 응답을 Unity Sprite와 게임 데이터로 변환

Implementation Notes

  • AI STAGE

    외부 생성 결과를 게임 데이터로 연결

    네트워크 응답에서 이미지와 좌표를 파싱한 뒤, 화면 크기에 맞춰 좌표를 변환하고 런타임 StageData를 생성해 곧바로 플레이할 수 있게 했습니다.

  • PROGRESS

    일반 스테이지와 커스텀 모드의 분기

    일반 스테이지는 클리어 기록·잠금 해제·점수 흐름을, 커스텀 스테이지는 저장·최고 기록 흐름을 따로 처리합니다.

  • UI

    게임 상태를 즉시 반영하는 UI

    남은 시간, 정답 수, 아이템 사용량, 결과 패널을 UI 요소와 연결해 플레이 상태를 지속적으로 보여줍니다.
