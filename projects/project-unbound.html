UNBOUND

Explore, fight, and overcome.

Project Overview

Player Experience

2D 맵을 이동하며 사다리·플랫폼·상호작용 요소를 지나 적과 전투합니다. 공격, 패링, 회복, 체력 UI와 사운드가 기본 플레이 감각을 구성합니다.

World Progression

맵 위치와 현재 위치 마커, 키와 보스 문, 보스 전투, 저장 지점 메시지, 튜토리얼, 상점과 크레딧 화면을 통해 탐험·전투·진행 요소를 연결합니다.

Implemented Features

  • 플레이어 이동·사다리·슬라이드·입력 잠금 등 2D 조작 구성
  • 근접 공격·피해 처리·패링·회복·HP Bar 기반 전투 시스템
  • 일반 몬스터와 Hermes·Hephaestos 등 보스 공격 패턴
  • 맵 위치 데이터, 현재 위치 마커, 맵 전환과 가장자리 트리거
  • 키 힌트·보스 문·저장 지점·회복·패링 튜토리얼 UI
  • 넥타르·소울 획득, 상점 구매, 일시정지·오프닝·크레딧 화면

Implementation Notes

  • COMBAT

    플레이어와 적의 역할 분리

    플레이어 전투·피해·패링·회복을 개별 컴포넌트로 나누고, 적과 보스는 공격 패턴 및 피해 처리 컴포넌트로 구성해 전투 확장을 고려했습니다.

  • WORLD

    탐험 진행을 돕는 상호작용 레이어

    맵, 열쇠, 문, 저장 지점, 튜토리얼을 트리거와 UI로 연결해 플레이어가 다음 행동을 자연스럽게 이해할 수 있도록 했습니다.

  • POLISH

    게임 전반의 피드백 요소

    배경 음악, 타격 시 카메라 펄스, 체력·상태 UI, 오프닝과 일시정지 화면을 통해 플레이 흐름의 피드백을 보강했습니다.
