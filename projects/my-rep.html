PET CARE DIARY

MY REP

Daily records, made easy.

Project Overview

Goal

반려 파충류의 생활·건강 데이터를 날짜 단위로 기록하고 필요한 항목으로 빠르게 이동할 수 있는 모바일 경험을 설계했습니다.

Flow

Google 계정으로 로그인한 뒤 기존 사용자는 다이어리로, 신규 사용자는 프로필 설정으로 분기합니다. 기록 화면은 월간 캘린더와 요약·빠른 입력 액션을 연결합니다.

Implemented Features

  • Google Sign-In과 Firebase Authentication 기반 로그인
  • Firestore 사용자 문서 유무에 따른 온보딩 분기
  • 반려동물·사용자 프로필 설정 화면
  • 월 이동 및 날짜 선택이 가능한 Compose 캘린더
  • 식사 · 몸무게 · 탈피 · 병원 기록으로 이어지는 빠른 액션
  • 카테고리·제목·본문·사진 업로드 UI를 갖춘 커뮤니티 게시물 작성 화면

Implementation Notes

  • AUTH

    로그인 이후의 사용자 상태 처리

    Firebase 인증 완료 후 Firestore의 사용자 문서를 확인해 기존 사용자와 신규 사용자의 진입 화면을 구분하도록 구성했습니다.

  • UI

    Compose 상태 기반 다이어리 인터랙션

    선택 날짜와 현재 연월을 상태로 관리하고, 이전·다음 월 이동과 각 기록 화면으로의 이벤트를 분리했습니다.

  • DATA

    클라우드 서비스 연동 기반 확장성

    인증·문서 데이터·이미지 저장소를 Firebase 서비스로 구성해 계정 기반 기록 관리의 토대를 마련했습니다.
